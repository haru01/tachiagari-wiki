# 育成というテーマは当たったが「1on1の前後で使う道具」という置き場所が外れた

> **架空・実証拠として扱わない**（公開リポジトリ向けに脚色改変した架空事例。この学びに紐づく確信度は上限8・実観測の代わりに使わない）

学習元の試行: [[SELF-ACT-001]]

生データ: `sources/2026-07-28-third-party-架空-Mさん打診-tachiagari-wiki.md`（種別: third-party・架空）

### 学びの要点

持っていった仮説は「**次世代リーダーを育てたい → 育成の中心は 1on1 → だから 1on1 の前後で使う道具が響く**」という三段の連鎖だった。1人目のマネージャ（Mさん）の反応で外れたのは**3段目**である。育成というテーマは当たっていたが、Mさんは「**1on1 は1対1なのでこの課題は扱いきれない。別の場を作ってそこでやるほうがいい**」と返した。**外れたのは道具ではなく、こちらが置いた「1on1の前後」という置き場所**。ただし「使ってみたい」の判断・次の一歩は出ておらず、しかも**見せたのは README の説明文のみ**で道具への反応としては読めない——**打診の刺激が弱すぎた**ことも同時に判明した。

### 事実（observed）

- 2026-07-28・**約1時間**・Mさん（顧客企業のマネージャ・ACT-001 が想定した2人のうち**1人目**）。
- **見せたのは README の説明文のみ。デモは見せていない。**
- こちらが持っていった仮説: ①次世代リーダーを育てたい課題がある ②育成の中心は 1on1 ③ゆえに 1on1 の前後で使う道具が響く。
- 反応: 「**育てたいのはその通り。ただ、今の課題感に対しては 1on1 とは違うアプローチのほうが良さそう**」「**1on1 は1対1なので、この課題は扱いきれない。別の場を作ってそこでやるほうがいい**」。
- **「1on1 の前後で使ってみたい」という判断には至らなかった。** 対象メンバー・実施時期を伴う言明はなし。
- **「別の場」の具体（どの場で・何をやるのか）は聞き出せなかった**。面談中に書き留めておらず、面談後に思い出せなかった。
- 明確なリジェクト（要らない・使えない）の言葉は出ていない。出たのは**置き場所の置き換え提案**。
- 打診の前は「信頼を積んできた取り組みの延長で話せばいい」と思っていたが、Mさんの関心は別の経験に向いていた。
- 計画からの逸脱: **1時間**（許容損失は各15〜30分＝超過）、**デモ未提示**（方法は「同じデモを見せ」）。
- **2人目のマネージャは未実施**（2026-07-28 時点）。

### 解釈（inference）

- **判定は確定できない。** [[SELF-ACT-001]] の成功基準は n=2 で書かれており、1人目が次の一歩に至らなかっただけでは反証も支持も成立しない（反証は「2人とも面白いね止まり・要らない」が条件）。よって `outcome: 判断保留`——ただしこれは成功基準にある「1人が乗り1人が断る割れ」ではなく**2人目未実施による確定不能**である。
- **仮説の3段目だけが折れた**。riskiest-assumption（「1on1前の道具として使いたいと思う」）は1人目では成立しなかったが、テーマ（育成）と課題の実在は否定されていない。出てきたのは拒否ではなく**場の置き換え提案**であり、その理由が「1対1では扱いきれない」と明示されている。つまりこれは**需要の不在ではなく、置き場所の取り違え**と読める。
  - この読みは楽観に振れる危険があるので線を引く: 「置き場所を直せば道具は要る」とまでは言えない。**別の場に置き直したときに使いたいと言われた事実はまだない**（次の一歩に至っていない）。言えるのは「1on1 の前後という置き場所は棄却され、別の場という方向が相手から示された」ところまで。
- **この反応を需要の証拠として重く扱えない。** 刺激が README の説明文のみだったため、Mさんが反応したのは道具ではなく**説明文から想像された像**である。1on1 が合わないという判断も、その像に対して下されている。
- **1時間を手応えと読み替えない。** 時間を割いてもらったのは事実だが、次の一歩は出ていない。長く話せたことを確証に転化するのは偽の確証の典型で、[[SELF-P-001]] がもともと警戒している経路（「動いた」で満足する）に近い。
- **面談者の気づき**（事実ではなく本人の判断）: 「**キー体験のわかりやすいデモがあってもいい。今の見栄えはない**」。ACT-001 は「荒いまま見せて反応を取る／作り込みすぎると検証がぶれる」と意図的に決めていたが、実際には**反応を取れる下限を下回っていた**。荒さの許容と、伝わる最小形の欠如は別問題だった。
- **相手の内側の重みづけを読み違えていた**（信頼を積んだ取り組みの延長で話が通ると思っていた）。これは [[SELF-P-001]] が成否条件を「相手の前進」に置いた判断を裏付ける——自分の見立てだけでは相手の位置が分からない。
- **核心の具体が残らないことが2件連続**（[[SELF-LEARN-001]] の痕跡未確認、本件の「別の場」の具体）。面談中のメモ取りが仕組みとして弱い。相手側の問題ではなく自分の運用の欠陥。

### 驚き・想定外

- **テーマは当たり、置き場所が外れた。** 「育成に効く道具」ではなく「1on1 の前後」という自分の置き方が否定された。仮説を三段に分けて書いておいたので、どの段が折れたか分かった。
- **1対1では扱えないサイズの課題だった。** 個人と向き合う場ではなく、複数人が関わる場の設計の側に問題があった。
- **「別の場」を取り逃した。** 相手が示した代案の中身が残っていない。今回いちばん価値のあったはずのデータ。
